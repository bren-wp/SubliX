# SubliX 0.1.1 — Foundation preview

Two separate Android editions (Free / Pro) with independent package identities and device-local data. Dark-first BRENDIGO branding, subscription entry and editing, recurring cost calculations, renewal calendar, local payment history, archiving, optional reminder scheduling, manual JSON backup and restore, and a Pro budgeting control.

Includes a no-login marketing website, separate privacy/terms pages, original vector brand assets, and 20 illustrative screen design references.

**Preview status:** This is an initial implementation. Not all future features in the 20-screen specification are implemented. The screenshots are illustrative concepts, not verified production captures. Only use GitHub Actions verified signed artifacts for installation. See docs/RELEASE.md for limitations and signing requirements.


Maintenance changes: Removed GitHub Pages deployment automation; website remains source-only in the repository. Added an Android emulator screenshot capture pipeline and Free/Pro preview release signing fallback. **Without configured permanent signing secrets, generated builds are untrusted tests only and not stable upgrade/Play Store packages.**
