Privacy Policy

Last updated: 14 November 2026

What SubliX stores

SubliX Free and SubliX Pro store information you enter — subscription names, amounts in EUR, categories, renewal dates, optional trial dates, usage labels and any manually confirmed payments — in their own Android app storage. Pro additionally tracks price changes and stores category budget preferences locally.

No sign-up, no bank access

Neither Android edition requires an email address, user account, password, banking login or connection to a SubliX server. The app does not read your emails, SMS, bank account or other service accounts. The website is a static product presentation and has no user registration, forms or account database.

Optional permissions

Local renewal reminders may request Android notification permission. Declining that permission does not prevent you from tracking subscription records. Notifications may show a subscription name and price on your lock screen according to your device settings.

Manual exports and imports

The application can export JSON backups and manually import them using the device's document picker. Pro can also export CSV reports for subscriptions, forecasts and payments. These files are currently unencrypted: store them in a private location and delete copies you no longer need. SubliX does not silently transfer these files to a cloud service. The file provider or destination you choose may have its own privacy practices.

Separate Free and Pro storage

Free and Pro are independent Android packages. Data does not synchronize between them automatically. Moving records requires exporting from one edition and importing into the other. Android automatic backup of the app's private data is disabled in the current project configuration.

Website and links

The website source is stored in the public GitHub repository but is not published as a GitHub Pages site. The code has no advertising SDK, tracking cookies, user accounts or external font service. If you open source files, GitHub Releases or other external links on GitHub, their service terms and logging policies apply. Any third-party static hosting chosen separately should be assessed and disclosed before publication.

Limits of the service

SubliX never processes payments and cannot cancel your subscriptions with external providers. All dates and costs depend on the information you enter. This description must be reviewed again if future releases add connectivity or services that change how user data is handled.
